# Issue tracker: GitHub

Issues and specs for this project live in the private repository `ChindanaiNaKub/civet-behavior-detection`. Use the `gh` CLI with `--repo ChindanaiNaKub/civet-behavior-detection` for explicit repo targeting.

- Create: `gh issue create --repo ChindanaiNaKub/civet-behavior-detection --title "..." --body-file <path>`
- Read: `gh issue view <number> --repo ChindanaiNaKub/civet-behavior-detection --comments`
- List: `gh issue list --repo ChindanaiNaKub/civet-behavior-detection`
- Comment/edit/close: use `gh issue comment`, `gh issue edit`, or `gh issue close` with the same `--repo` value.

PRs as a request surface: no.

When a skill says to publish work to the issue tracker, create a GitHub issue in this repository.
