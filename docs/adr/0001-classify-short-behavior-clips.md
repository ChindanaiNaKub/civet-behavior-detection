# Classify short behavior clips

Phase 2 will adapt the image-classification task into short-clip behavior classification. Locomotion depends on visible movement and Resting depends on duration, so a single still image cannot support the Phase 1 behavior definitions; short clips preserve those definitions without requiring the bounding-box annotations of the YOLO option. This deliberately adapts the task wording in the Phase 2 brief and should be made explicit in the project plan.
